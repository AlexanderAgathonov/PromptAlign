# PromptAlign: Автоматическое итеративное выравнивание LLM под экспертную разметку

Этот репозиторий содержит сопутствующий код к научной статье:
> **Агафонов А.А., Хусаинов А.Р., Прокопьев Н.А.** (2026). PromptAlign: автоматическое итеративное выравнивание большой языковой модели под экспертную разметку без дообучения. *Электронные библиотеки*, Т. 1, № 1. [DOI: ВСТАВИТЬ DOI]

## Описание
Конвейер реализует метод автоматической оптимизации инструкций (prompt optimization) без доступа к весам модели. Он использует гибридные признаки, L1-регуляризованные суррогатные модели для локализации расхождений с экспертом и метаанализ ошибок для генерации интерпретируемых правил на естественном языке. Метод контролирует баланс классов с помощью индекса дисбаланса (Blanket Pulling Index, BPI).

## Требования
- Python 3.10+
- `pip install openai scikit-learn pandas numpy`

## Структура данных
Поместите файлы с текстами в папку `./data/`. Формат файлов: тексты разделены маркером `*********`. 
Пример структуры:
```text
data/
  0_1.txt  # Информативный класс, часть 1
  0_2.txt  # Информативный класс, часть 2
  1_1.txt  # Деструктивный класс, часть 1
  ...
```

## Запуск
1. Установите переменную окружения для API ключа:
   ```bash
   export DEEPSEEK_API_KEY="ваш_ключ"
   ```
2. Запустите основной скрипт:
   ```bash
   python promptalign.py
   ```

## Воспроизводимость
Все промежуточные состояния (предсказания, извлечённые признаки, сгенерированные правила) сохраняются в папке `./checkpoints/`. Это позволяет возобновить вычисления после обрыва связи без повторных затрат на API.
